# 🏛️ Словарь экономиста (Economics Hub)

Интерактивный учебный трёхъязычный словарь экономических терминов с академическим дизайном, тёмной темой, тренажёром памяти (флеш-карточками) и **отдельной изолированной панелью администратора**.

Проект переписан на современном стеке **React 19 + Vite 8** с модульной архитектурой компонентов, контекстов и локализации.

---

## ✨ Возможности

### 📖 Публичный словарь (`/`)
* 🌍 **Трёхъязычность (i18n):** Мгновенное переключение интерфейса и терминов между **Русским (RU)**, **Английским (EN)** и **Узбекским (UZ)** языками с автоопределением языка браузера.
* 🌓 **Светлая и тёмная тема:** Ночной режим с автоматическим определением системных настроек и сохранением выбора в `localStorage`.
* 📊 **Категории экономики:** Фильтрация по разделам (*Микроэкономика*, *Макроэкономика*, *Финансы и банки*, *Эконометрика*, *Мировая экономика*, *Другое*).
* 🔤 **Алфавитный навигатор:** Горизонтальная лента букв с динамической адаптацией под алфавит выбранного языка (кириллица / латиница).
* 🔍 **Живой поиск:** Мгновенный поиск по терминам, академическим определениям и формулам/примерам сразу на всех трёх языках.
* 🧠 **Тренажёр карточек (Flashcards):** Интерактивные 3D-карточки для запоминания и подготовки к экзаменам (с поддержкой горячих клавиш: `Space` — перевернуть, `←` / `→` — навигация, `Esc` — закрыть, перемешивание колоды).
* 📋 **Быстрое копирование:** Копирование термина с определением и примером в буфер обмена в один клик.

### 🛡️ Отдельная панель администратора (`#/admin`)
* 🔒 **Защищённый вход:** Доступ по секретному паролю (`samsueconomics`).
* 📊 **Аналитические метрики (KPI):** Общее количество терминов, процент трёхъязычной полноты базы, распределение по разделам.
* 📋 **Интерактивная таблица CRUD:**
  * Добавление новых экономических терминов с удобными вкладками языков (RU / EN / UZ).
  * Редактирование любых существующих терминов.
  * Удаление терминов с модальным окном подтверждения.
  * Поиск и фильтрация по категориям прямо внутри админки.
* 💾 **Экспорт и импорт:**
  * Экспорт всей базы в файл `economics_terms_YYYY-MM-DD.json`.
  * Импорт из JSON-файла или вставка JSON-массива через текстовое поле с валидацией.
  * Сброс базы до стандартных 10 академических терминов.

```text
economics/
├── public/                 # Статические ресурсы (иконки, фавиконка)
├── src/
│   ├── components/         # UI-компоненты
│   │   ├── admin/          # Компоненты админ-панели
│   │   │   ├── ImportModal.jsx   # Модальное окно импорта JSON
│   │   │   └── TermModal.jsx     # Модальное окно создания/редактирования термина
│   │   ├── AlphabetFilter.jsx    # Алфавитный навигатор
│   │   ├── CategoryFilter.jsx    # Чипсы разделов экономики
│   │   ├── FlashcardTrainer.jsx  # Тренажёр флеш-карточек (3D flip)
│   │   ├── Footer.jsx            # Футер с академической подписью и секретным входом
│   │   ├── Navbar.jsx            # Шапка (логотип, язык, тема, тренажёр, статус)
│   │   ├── TermCard.jsx          # Карточка термина с примерами и копированием
│   │   └── Toast.jsx             # Всплывающие уведомления
│   ├── constants/          # Константы и словари
│   │   ├── alphabets.js    # Алфавиты для RU и LAT
│   │   ├── categories.js   # Список разделов экономики и бейджи
│   │   ├── i18n.js         # Полная локализация интерфейса (RU / EN / UZ)
│   │   └── starterTerms.js # Стартовая база из 10 фундаментальных терминов
│   ├── context/            # React Context (Глобальное состояние)
│   │   ├── AuthContext.jsx     # Аутентификация администратора
│   │   ├── LanguageContext.jsx # Управление языком и переводами
│   │   ├── TermsContext.jsx    # CRUD базы терминов, localStorage и импорт/экспорт
│   │   ├── ThemeContext.jsx    # Управление светлой/тёмной темой
│   │   └── ToastContext.jsx    # Управление всплывающими тостами
│   ├── pages/              # Главные экраны (страницы)
│   │   ├── AdminPage.jsx       # Полноценная студия администрирования
│   │   └── DictionaryPage.jsx  # Публичный интерактивный словарь
│   ├── App.jsx             # Корневой компонент с HashRouter и провайдерами
│   ├── index.css           # Дизайн-система (переменные, светлая/тёмная тема, стили)
│   └── main.jsx            # Точка входа Vite
├── legacy/                 # Резервная копия старых файлов (Vanilla HTML/CSS/JS)
├── index.html              # HTML-шаблон Vite
├── package.json            # Зависимости (React 19, Lucide, React Router, Vite)
└── vite.config.js          # Конфигурация сборщика Vite
```

## 🚀 Запуск и разработка

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере адрес, указанный в консоли (обычно `http://localhost:5173/`).

### 3. Сборка для продакшена
```bash
npm run build
```
Готовая оптимизированная сборка будет в папке `dist/`.
