# 🏛️ Словарь экономиста (Economics Hub)

Интерактивный учебный трёхъязычный словарь экономических терминов с академическим дизайном, тёмной темой и тренажёром памяти (флеш-карточками).

---

## ✨ Возможности

* 🌍 **Мультиязычность:** Полная поддержка трёх языков — Русский (RU), Английский (EN), Узбекский (UZ).
* 🌓 **Светлая и тёмная тема:** Удобный ночной режим с переключателем в шапке и сохранением выбора.
* 📊 **Категории экономики:** Фильтрация по разделам (Микроэкономика, Макроэкономика, Финансы и банки, Эконометрика, Мировая экономика, Прочее).
* 🔤 **Алфавитный навигатор:** Быстрый переход по буквам термина.
* 🔍 **Живой поиск:** Мгновенный поиск по терминам, определениям и примерам.
* 🧠 **Тренажёр карточек (Flashcards):** Интерактивные карточки с 3D-переворотом для подготовки к экзаменам.
* 🔒 **Защищённый режим автора:** Служебный доступ для добавления и редактирования карточек (скрыт от обычных посетителей).
* 💾 **Резервное копирование:** Экспорт и импорт базы терминов в формате JSON.

---

## 🚀 Запуск

Проект написан на чистом стеке (HTML5, CSS3, JavaScript ES6+) без сборщиков и внешних зависимостей.

1. Склонируйте репозиторий или скачайте архив:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   ```
2. Откройте файл `index.html` в любом современном браузере.
